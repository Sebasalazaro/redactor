# Security

This is a personal tool, shared as is and without support. If you find a
vulnerability, or a value that should have been redacted but wasn't, you can
report it through a private
[security advisory](https://github.com/Sebasalazaro/redactor/security/advisories/new).
Use **fictional** data only. There is no promised response time, and only the
latest release gets fixes.

Release files can be checked against `SHA256SUMS` and with:

```sh
gh attestation verify <file> --repo Sebasalazaro/redactor
```
